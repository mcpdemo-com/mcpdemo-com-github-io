What's happening under the hood?

When you submit a query, the demo calls a Cloudflare Worker at api.mcpdemo.com. The Worker holds a Supabase Personal Access Token securely — it's never sent to your browser.

The Worker forwards your question to Claude via the Anthropic Messages API, with Supabase's hosted MCP server at mcp.supabase.com/mcp wired in as an MCP tool. The URL is scoped with project_ref and read_only=true, and only the database feature group is exposed — so Claude can call list_tables and execute_sql on one specific demo project, and nothing else.

Results come back as structured data. Claude explains them in plain English and the page renders any tabular output. Responses stay on this page — no links out, no outbound navigation.
